## Lecture 1
- Elementary logic vocabulary: proposition (statement that may be either true or false); proof (demonstration that one proposition follows from one or more others); axiom (accepted without proof); theorem (proved on basis of axioms and previously established theorems). P ⇒ Q ("if P then Q"); P ⇔ Q when both directions (equivalent). Negation "not P".
- Sets: collection (what is a collection?) of objects; A={x,y,z,...}; x∈A element; x∉A; A=B if every element of A in B and vice versa; empty set ∅ or {}. Remark: no "set of all sets" (Russell's Paradox).
- A⊆B (some textbooks A⊂B) subset/superset; A=B ⇔ (A⊆B and B⊆A); A∩B intersection; B∩A=A∩B; A∪B union (or both); B∪A=A∪B. Example fruits: E={oranges, strawberries}, B={oranges, apples, bananas}, H={bananas, blueberries, apples}, S={bananas, oranges, apples, blueberries}: B∩H={apples, bananas}; B∪H=S; S∩E={oranges}=B∩E; E∩H=∅; B⊆S, H⊆S; any set subset of itself.
- Set-builder {x∈A | x has property P}; example QMUL students born after 2005.
- Set subtraction A∖B={x∈A | x∉B} difference; examples {apples, oranges, blueberries}∖{bananas, oranges}={apples, blueberries}; {2,4,6,...}∖{3,6,9,...}={2,4,8,10,14,...}; A⊆B ⇒ A∖B=∅.
- Number systems: N={1,2,3,...} successor property n∈N ⇒ n+1∈N; Z; Q = p/q with p∈Z, q∈N; R (informally) points on number line. N⊆Z⊆Q⊆R. Q adequate for arithmetic (+,−,×,÷); R needed for algebra (x²=2), geometry (circumference/diameter), limits.
- Properties of R: Order O1 trichotomy (exactly one of a>b, a=b, a<b); a<b same as b>a; ≥, ≤ defined; O2 transitivity. Addition A1 commutativity, A2 associativity, A3 a+0=a, A4 a+(−a)=0, A5 a>b ⇒ a+c>b+c. Multiplication M1 commut., M2 assoc., M3 1≠0, a·1=a, M4 a·(1/a)=1 for a≠0, M5 distributive a(b+c)=ab+ac, M6 a>b, c>0 ⇒ ac>bc; a>b, c<0 ⇒ ac<bc.
- Least Upper Bound property (extra material, NON-EXAMINABLE): Q satisfies all above; R also: non-empty A⊆R bounded above has least upper bound z (x≤z ∀x∈A; ∀w<z ∃x∈A: x>w).
- Intervals: [a,b], (a,b), (a,b], [a,b), (a,∞), (−∞,b), (−∞,∞)=R, [a,∞), (−∞,b] — set-builder definitions.
- Basic inequalities ("ideas behind solving... rely on properties of real numbers. When solving problems, it suffices just to do correct calculations"): Ex1 2x+1>0: A5 & A4 add −1, A2–A4 simplify, A1, A3: 2x>−1; reverse by adding 1 ⇒ equivalent; M4 inverse 1/2 >0, M6 multiply: x>−1/2; reverse; solution x∈(−1/2,∞).
- Ex2 (2x+1)(x−1)>0: neither factor zero; 4 sign cases; ⇔ [both >0] or [both <0]; [2x+1>0 and x−1>0] ⇔ x>1 (since x>1 ⇒ x>−1/2); [both<0] ⇔ x<−1/2; solution (−∞,−1/2)∪(1,∞).
- Ex3 quadratic 3x²−5x+2>0: idea e(x+f)(x+g); expanding e=3, f+g=−5/3, fg=2/3; x=−f root; D=(−5)²−4·3·2=1; x=(5±1)/6 → 2/3, 1; 3x²−5x+2=3(x−2/3)(x−1); solution (−∞,2/3)∪(1,∞).
- Summation operator Σ_{j=k}^n a_j = a_k+...+a_n; examples Σ_{j=3}^7 j=25; Σ_{j=−2}^3 j=3; Σ_{3}^7 j²=135; Σ_{−2}^3 j²=19. One term Σ_{j=k}^k a_j = a_k; empty Σ_{j=k}^{k−1} a_j = 0 (defined, by analogy); constant Σ_{j=k}^n a = (n−k+1)a. Properties P1 Σ(a_j+b_j)=Σa_j+Σb_j; P2 Σ c a_j = cΣa_j (from properties of reals); P3 Σ_{k}^n + Σ_{n+1}^m = Σ_k^m for k≤n≤m (from definition).
- Next week preview: Mathematical induction (base P1, step Pn⇒Pn+1, induction hypothesis; domino animation P1⇒P2⇒P3...), example Σ_{j=1}^n j = n(n+1)/2 (base: 1=1; step: Σ^{n+1} = n(n+1)/2 + (n+1) = (n/2+1)(n+1) = (n+2)(n+1)/2); alternative step for n≥2: P_{n−1} ⇒ P_n; alternative formulation (strong): (P1 and ... and Pn) ⇒ P_{n+1}, equivalent.
## Lecture 2 (Plan Lectures 2–4; outline: induction, absolute value, binomial formula, functions & polynomial, sequences & limits intro)
- Induction repeated (as above).
- Absolute value: |x|=x if x≥0, −x if x<0; equivalently |x|=max{x,−x}; examples |2|=2, |−5|=5, |7/3|=7/3, |−√11|=√11, |0|=0 (checked image). Properties: |a|≥a; |a|≥−a; |−a|=|a|; |ab|=|a||b|; |a/b|=|a|/|b| (b≠0).
- Triangle inequality (Problem B1 from HW-1): |x−z| ≤ |x−y|+|y−z| (distance interpretation); apply to prove |a+b|≤|a|+|b| and |a|≤|a−b|+|b|. (Proof "see notes" — not in slides.)
- Binomial formula: (x+y)^n for n∈{0}∪N; expansions n=0..5 (1; x+y; x²+2xy+y²; x³+3x²y+3xy²+y³; x⁴+4x³y+6x²y²+4xy³+y⁴; x⁵+5x⁴y+10x³y²+10x²y³+5xy⁴+y⁵). General (x+y)^n = Σ_{j=0}^n C_n^j x^{n−j} y^j, C_n^j = n!/((n−j)! j!). Binomial coefficient defined for j,n∈{0}∪N with n≥j; notation C_n^j (more common (n choose j)). Factorial recursive 0!=1, k!=(k−1)!·k; 0!,1!,...,5! = 1,1,2,6,24,120; C_5^2 = 5!/(3!2!) = 10.
- Function: informal rule associating each element of domain D with element of codomain R; formal: set of ordered pairs (x,y) with unique y for each x; y=f(x). Examples g(x) mass of object (g(Jupiter)≈1.898×10^27 kg); h(x)=x² on R (h(10)=100, h(−1)=1). Equal functions: same domain, codomain, values. Numerical function: D,R⊆R.
- Polynomial f(x)=Σ_{k=0}^n a_k x^k; coefficients; degree = largest k with a_k≠0 (if at least one non-zero); monomials (terms); root x̄ with f(x̄)=0.
- Theorem L2.1: polynomial p of degree n≥1 with root x̄ ⇒ unique polynomial q of degree n−1 with p(x)=(x−x̄)q(x). Proof by (strong) induction on n: base n=1: p=a1x+a0, a1≠0, unique root −a0/a1, q=a1; uniqueness. Step: assume true for all 1≤k<n. Case 1: p(x)=(x−x̄)a_n x^{n−1}. Case 2: s(x)=p(x)−a_n x^{n−1}(x−x̄) = (a_{n−1}+a_n x̄)x^{n−1}+...+a0 ≠0; s(x̄)=0; degree k with 1≤k≤n−1 [note: degree could be 0? s nonzero with root ⇒ degree≥1]; by hypothesis s=(x−x̄)r(x), deg r = k−1 ≤ n−2; p = (x−x̄)(a_n x^{n−1}+r(x)). [Uniqueness part of step not fully shown in slides — flag.]
- Quantifiers: ∃x∈A : P ("there exists at least one"); ∀x∈A, P ("for all"). A={2,4,6,8,10,12}: ∃x∈A: x≥10; ∀x∈A, x<20.
- Sequences: infinite ordered list (x1,x2,...), formally function x: N→R (x_n=x(n)); examples coin flips (T,T,T,T,H,T,T,T,H,H,...); macro series x_t=(output, employment, debt, inflation). Numerical sequence: each x_k∈R; examples constant (7,7,...); b=(3,3.1,3.14,3.141,...) digits of π; c_n=f(b_n), f(x)=x²−9.5: (−0.5, 0.11, 0.3596, 0.365881,...); d: ln(n) truncated (0,0.69,1.09,1.38,1.60,1.79,1.94,...). Notation x, (x_n), (x_n)_{n∈N}, (x_n)_{n=1}^∞.
- Behaviour at infinity: a_n=2^{−n} → 0; (b_n) with 1/256 repeated → 1/256; first elements don't determine behaviour at infinity.
- Definition limit: x∈R is a limit of (a_n) if ∀ε>0 ∃N∈N: ∀n>N, |a_n−x|<ε; then converges (finite limit). Ex1 2^{−n}: ε=1: N=1; ε=0.1: from a4=1/16, N=3; ε=0.01: a7=1/128, N=6; ε=0.003: a9=1/512, N=8. Remark: N=100 works for all those; any N that works is fine; "for large enough n". Formal proof: 2^{−n}<ε ⇔ n>−log2 ε; take N>−log2 ε.
- Ex2 b_n=1+1/n → 1: N=⌈1/ε⌉; n>N: |b_n−1|=1/n<1/N≤ε.
- Ex3 c_n = 1,0,1,0,... no finite limit: contradiction with ε=1/4: |1−x|<1/4 and |0−x|<1/4 ⇒ 1 ≤ |1−x|+|x−0| < 1/2 (triangle inequality HW-1).
